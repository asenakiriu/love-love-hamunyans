# らぶ🥰はむ❤️ — Love Love Hamunyans

> 日常の会話を通じて、自分専用のAIサポート部隊との理解と関係性を深める。

`love-love-hamunyans` は、スマートフォンゲームのUIと、日常の相談・雑談・作業支援を行うAIアシスタントを組み合わせた個人開発プロジェクトです。

5匹のハムスターと1匹の猫からなる「はむにゃんず」と会話し、必要に応じてキャラクターに触れて「むぎゅー」できます。最初の利用者は開発者自身です。

## 設計方針

- 会話ファースト。頻出する操作だけをゲームUI化する。
- AIは利用開始時から最大限の能力でサポートする。
- むぎゅー回数・好感度・経験値によって、AIの能力や利用可能な機能を制限しない。
- 会話や記憶の訂正を通じて、ユーザーへの理解を深める。
- 日課やログインを強制せず、育成を負担にしない。

## MVPのゴール

**現在のはむにゃんずとの日常会話を、自作アプリで楽しめること。**

- 6人のキャラクター表示
- 自由入力による会話とキャラクター別の吹き出し
- キャラクターへのむぎゅーとリアクション
- 会話履歴の永続化
- 基本的な長期記憶と訂正
